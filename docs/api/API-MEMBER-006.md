## 2. 功能与适用场景

返回站长定义的头衔目录；默认只含 visible=1 的条目，include_hidden 可查看全部。

**适用场景**：主题渲染头衔徽章样式表；控制台展示可选头衔。

**实现备注**：头衔定义不是机密：隐藏头衔只是「不默认展示」，不是访问控制。真正的访问控制仍在权限系统。

## 3. 请求规范

- 路径版本前缀：`/api/v1`；路径使用 kebab-case 复数资源名，不在路径中放动词。
- 请求体为 JSON（`Content-Type: application/json`）；GET / DELETE 使用查询参数。
- 建议携带 `X-Request-Id`，服务端会原样回填 `request_id`，用于链路追踪。

| 参数 | 位置 | 必填 | 类型 | 说明 |
| --- | --- | --- | --- | --- |
| `include_hidden` | query | 否 | `bool` | 是否包含隐藏头衔，默认 false |
